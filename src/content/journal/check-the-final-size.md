A large source file gives you room to arrange artwork, but the final viewing size determines which details remain visible. Zooming in can make a crowded composition look comfortable. Make a smaller proof early, while changing the layout is still easy.

## Set the destination first

Decide whether you are composing a square thumbnail, a tall post or a wide banner. Start a canvas with the proportions you need. Keep the original artwork in a separate file so the working layout does not become the only copy.

### Review at normal viewing size

For a screen layout, inspect an exported copy at the intended display size. For a physical layout, make an actual-size proof when practical. The zoom percentage in an editor alone does not tell you how someone will encounter the work.

## Look at gaps, not just lines

Thin strokes may fade, but the spaces between strokes can also close up. Inspect places where several branches meet. If a central knot becomes a dark patch, try a larger placement or a less detailed design.

> The useful detail is the detail that survives the final view.

## Use a short review list

- Can you still recognise the overall silhouette?
- Are neighbouring branches visibly separate?
- Does the crop leave the important endpoints intact?
- Is the title readable without zooming in?

## Keep the proof beside the original

Save the small test separately from the editable source. If the result feels too busy, change the source composition and export again. Repeatedly resizing the same flattened image makes comparisons harder to track.
