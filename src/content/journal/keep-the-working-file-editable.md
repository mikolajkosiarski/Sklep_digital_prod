A finished post may be a single image, but the file behind it benefits from a little structure. A later change to a title, crop or background should be a small revision. Set up the working document so those elements can move independently.

## Separate the main elements

Use distinct layers or groups for the background, artwork, lettering and supporting details. Give them short names that describe their role. A few clear names are easier to scan than a long sequence of numbered copies.

### Keep alternatives together

When comparing two crops or ornaments, place them in clearly labelled groups and show one at a time. Avoid leaving several almost identical shapes visible on top of one another. The document should make the current choice obvious.

## Save before flattening

Keep an editable source and export a separate preview. Give the export a name that identifies its destination and revision. This makes it easier to tell a square thumbnail from a tall post without opening every file.

> The export is one version of the composition. Keep the decisions editable in the source.

## A compact file structure

- Background and texture.
- Main artwork.
- Title and supporting text.
- Optional crop or placement alternatives.
- Exported previews in a separate folder.

## Leave a note for the next session

Record the chosen dimensions, the source pack and the last unresolved decision. A short note is enough. When you return to the composition, you can continue from a clear starting point instead of rebuilding its history from filenames.
