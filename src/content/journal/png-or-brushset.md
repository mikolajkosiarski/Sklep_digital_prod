A digital design pack can contain images, brushes, or both. These files serve different purposes. Before choosing a pack, think about your next step: do you want to place a complete design into a layout, or work with brushes inside Procreate?

## Two ways to use a design

A PNG is an image made from pixels. Place it in an application that supports PNG, then position and scale it within your composition. It is a useful starting point when you want to arrange a finished ornament beside lettering or combine several designs on separate layers.

A `.brushset` is a collection of Procreate brushes. It belongs in the Brush Library, where you select a brush to make marks on your canvas. The result depends on that brush's settings, the size you choose, and how you use it. Importing an image and importing a brush set are separate actions.

## Transparent or white background?

### A quick background check

A transparent PNG lets the underlying background show around the artwork. Choose it when you want a design to sit over a colour, photograph, or another graphic. A white-background PNG includes its white rectangle, which may be useful when you want an opaque image on the page. Test the file over a contrasting colour to see which version you have.

## Check the contents of the pack

The Visamore 100-, 200- and 300-design collections include PNG files and a Procreate brushset. The 25-, 55- and 121-design collections contain transparent and white-background PNG files without a brushset. Choose according to the files you need; a larger design count does not tell you which formats are included.

## Import into Procreate

- **For a PNG:** open your canvas, then choose Actions → Add → Insert a file. Find and select the image in Files. This route is documented in the [Procreate Handbook: Add](https://help.procreate.com/procreate/handbook/actions/actions-add).
- **For a brushset:** open the Brush Library and choose Import from Files, then select the `.brushset` file. The imported set appears at the top of the current library. See [Procreate Handbook: Import and Share](https://help.procreate.com/procreate/handbook/brushes/brushes-share) for the current interface.

## Before building the full composition

> Choose the file for the action you want to take next: place an image, or work with a brush.

Try one design first. Check its edges at the size you intend to use, make sure the background behaves as expected, and keep the original download. This small test makes it easier to choose the right file before arranging an entire page.
